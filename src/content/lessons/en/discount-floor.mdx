  - id: stack
    title: The second one
    narration: >-
      One marketer set up the category sale in May. Another set up the coupon in

    note: Each promo is fine. The pair is not.

  - id: clamp
    title: Clamp it at cost
    narration: >-
      This is the first fix anyone reaches for. The customer pays 32.00, the
      incident is closed. Three numbers under the code: 3200 paid, 1800 actually
      discounted, 4000 in the report. The report asks the promo engine, not the
      receipt. The money stopped leaking and the books started lying.
    note: The number is fixed. The report is not.

    title: Write the whole rule down
    narration: >-
      Any item, any set of promos. Lean does not answer "could not prove it" - it

      build and stays there. This is no longer a suspicion.
    note: Not unproven — disproven, with the pair attached.

    title: One shared pool
    narration: >-

      is one line: the total is cost plus what remains, and what remains is never
      negative.
    note: Discounts spend margin. There is no more to spend.

Discount engines do not fail because a mechanic is wrong. They fail because
mechanics multiply and nobody owns their combinations.

Marketing sets up promos through an admin panel. No developer hears about it. The
number of pairs grows quadratically; the number of tests does not.

The damage is quiet - not an exception, a sale. It surfaces either at month end,
in margin per SKU, or when a deal site finds the combination first.

## Where this shows up

Shipping rules, tariff plans, loyalty tiers, marketplace commission schedules.
Anywhere rules compose and nobody owns the sum.

## What this is not

This is not a claim that pricing cannot ship without a proof assistant. It is a
claim about what kind of sentence you need. "This pair is fine" is a test, and
there will never be enough of them. "No set of promos takes the price below cost"
is a different sentence, and it is the one the business meant.

The `Pricing.lean` file from this lesson compiles as a whole: Lean 4.34, no
errors. The numbers in the output are what the compiler printed.
