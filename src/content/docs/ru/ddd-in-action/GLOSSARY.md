# Словарь

Одно значение на слово внутри контекста. Код, события, API и человек на созвоне
пишут его одинаково.

## «Платёж» в трёх отделах

| Отдел | Что он называет платежом | Как это называется здесь |
| --- | --- | --- |
| Продукт | Покупка прошла, пользователь увидел галочку | Событие заказа. Здесь его нет |
| Процессинг | Деньги захолдированы, списания не было | **Авторизация** |
| Бухгалтерия | Деньги пришли выпиской через два дня | **Поступление** |

## Слова

**Авторизация.** Эмитент согласился держать сумму. Деньги не двигались, холд
истекает сам.

**Списание.** Команда забрать захолдированное. С этого момента деньги ушли со
счёта плательщика.

**Поступление.** Деньги дошли до нашего счёта, и это подтверждено выпиской
провайдера. Приходит днями позже и может не прийти вовсе.

**Платёж.** Попытка получить деньги за один заказ, со своим жизненным циклом:
авторизован, списан, возвращён. Слово значит это и ничего больше.

## Слова, которых здесь нет

**Покупка.** Продуктовое событие: пользователь увидел галочку. Живёт в заказах,
здесь ему нечего значить.
