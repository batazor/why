# why

Каталог уроков, объясняющих по шагам, зачем нужен тот или иной приём в разработке
и какую боль он снимает. Статический сайт, две локали (`en` по умолчанию, `ru`).

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # проверка консистентности + сборка в dist/
```

## Принципы, на которых держится структура

**Шаги — это данные, а не вёрстка.** Урок описывает последовательность шагов, а
плеер решает, как её показать. Добавить урок = добавить два файла, а не
сверстать новую страницу.

**Код общий, проза переводится.** Код и вывод программы лежат в `src/code/<deck>.ts`
в одном экземпляре на все локали, нарратив — в `src/content/lessons/<locale>/`.
Если положить код в переводимый файл, версии разъезжаются: правишь пример в en,
забываешь в ru, и получаешь баг, который воспроизводится только на одном языке.

Следствие правила: **код и вывод всегда на английском и без объясняющих
комментариев** — иначе русский комментарий вылезет на английской странице.
Вся проза идёт в `narration`.

**Одна спека, один рендерер.** И схема разбора, и постер проблемы описаны одним
типом `FlowSpec` и рисуются одним компонентом `FlowDiagram`. Отличие постера в
одном поле: `fixedStep` — схема из единственного состояния, которая не слушает
плеер и не даёт себя таскать и зумить. Ни второго формата, ни второго набора
проверок, ни рассинхрона между карточкой каталога и страницей урока.

Узел — обычная HTML-карточка: переносы считает браузер, вёрстка живёт в CSS,
y-смещения подписей подбирать не нужно. Ради этого движок и взят.

Цена: React и React Flow грузятся на всех страницах со схемами, включая каталог.
Это сознательный размен в пользу читаемости и единообразия схем. Атрибуцию
React Flow убрать нельзя — `hideAttribution` у них платный, поэтому она просто
сделана ненавязчивой.

**Два режима на одних данных.** Урок со схемой читается скроллителлингом: все шаги
видны, колонка нарратива прокручивается, схема прилипает полосой сверху и следует
за текстом. Активным считается шаг, пересёкший среднюю полосу экрана
(`IntersectionObserver` с `rootMargin: -48%`). Колесо мыши работает как обычно —
перехвата скролла нет, меняется только липкая панель.

Урок без схемы остаётся кнопочным плеером: виден один шаг, листается кнопками.

Схема стоит именно полосой сверху, а не колонкой сбоку: в колонке 23rem панель кода
обрезалась на середине строки, а отдать ей ширину можно было только отняв её у схемы.
Полосой сверху оба получают всю ширину разбора.

**Плеер — прогрессивное улучшение.** Все шаги рендерятся в HTML и без JS читаются
как обычная статья. Скрипт лишь добавляет классу контейнера `is-enhanced` и
переключает видимость. Это бесплатно даёт SEO, доступность и печать.

## Как добавить урок

1. `src/code/<slug>.ts` — колода шагов: `{ id, lang, caption?, code, output?, outputTone? }`.
   Подсветка задаётся маркерами в коде, а не номерами строк — номера разъезжаются
   при любой правке примера:

   ```ts
   signal: AbortSignal.timeout(3000), // [!code highlight]
   headers: { 'Idempotency-Key': key }, // [!code ++]
   ```

2. `src/code/<slug>.poster.ts` + `export const poster = posterSpec` — иллюстрация
   проблемы: тот же `FlowSpec`, но с `fixedStep` и `compact: true`. Показывается
   в карточке каталога и в блоке «Проблема». Без неё каталог из десятка уроков
   превращается в список одинаковых абзацев.

3. `src/code/<slug>.flow.ts` со спекой для React Flow и `export const flow =
   flowSpec` в колоде — схема разбора. Узлы и рёбра говорят, на каких шагах они
   активны:

   ```ts
   { id: 'open', kind: 'state', title: 'Open', focus: ['open'], active: WITH_BREAKER }
   { id: 'trip', source: 'closed', target: 'open', label: 'failures ≥ 5', only: ['open', 'recover'] }
   ```

   Координаты проставляются руками: React Flow не раскладывает граф сам, и это к
   лучшему — авторская раскладка читается лучше автоматической. Держи зазор между
   узлами шире самой длинной подписи ребра: она живёт в этом зазоре и иначе
   налезет на карточку. Подписи короткие — подробности несёт нарратив.

   Код у шага может отсутствовать вовсе: шаг бывает чисто схемным.

   **Пометки поверх схемы** (приём из overview-примера React Flow) — стикер со
   стрелкой, объясняющий, ради чего шаг. Разделены надвое, потому что пометка это
   проза, а вся проза переводится:

   ```ts
   // спека схемы — только геометрия
   annotations: [{ step: 'store', position: { x: 530, y: 248 }, arrow: 'left' }]
   ```
   ```yaml
   # локализованный урок — только текст
   - id: store
     note: >-
       Уникальность не твоя, а базы.
   ```

   Номер на стикере совпадает с номером шага в плеере — взгляду не нужно искать
   соответствие между текстом слева и картинкой справа.

   Текст пометки набран **Caveat** — рукописное начертание отделяет ремарку от
   схемы сильнее любой рамки. Технические подписи рёбер остаются системным
   шрифтом: там важна разборчивость, а не интонация.

   Пометка — укол, а не абзац: **лимит 80 символов**, это две строки. Длинная
   разрастается на четыре и ложится на узлы и рёбра, потому что место под неё в
   спеке фиксированное. Лимит проверяет сборка.

   Если спека резервирует пометку, а перевода для неё нет — сборка падает.

   Схема живёт в React-острове (`client:visible`), а навигация по шагам осталась
   в ванильном плеере. Связь через DOM: плеер пишет `data-step-id` на себя и шлёт
   событие `why:step`. Остров при монтировании сначала читает атрибут — он
   грузится лениво, и к этому моменту читатель может быть уже на пятом шаге.

4. `src/content/lessons/en/<slug>.mdx` и `.../ru/<slug>.mdx` — нарратив. Шаги
   связываются с колодой по `id`; тело MDX идёт до разбора как вводная статья.

5. `npm run check:steps` — проверяет то, чего не видит zod-схема:

   - расхождение состава и порядка шагов между локалями;
   - расхождение квизов (прогресс лежит в `localStorage` под общим ключом урока,
     значит индексы ответов обязаны совпадать);
   - ссылки схемы и постера (`only`, `active`, `focus`, `bad`) на несуществующие
     шаги, а рёбер — на несуществующие узлы; постер проверяется тем же кодом,
     только список допустимых шагов у него равен `[fixedStep]`;
   - постер без `fixedStep` — он рисуется вне плеера и обязан быть одношаговым;
   - пометку на схеме без `note` в какой-нибудь локали, и `note` без пометки —
     первое оставит пустой стикер, второе спрячет написанный текст;
   - `note` длиннее 80 символов — он разъедет на четыре строки и ляжет на схему;
   - кириллицу в колоде, схеме и постере — это общие ассеты, только английский;
   - выход `quiz.answer` за границы `options`.

   Встроено в `npm run build`, ошибка ломает сборку.

## Структура

```
src/
  code/<slug>.ts              колоды кода — общие для всех локалей
  code/<slug>.flow.ts         схема разбора: спека для React Flow
  code/<slug>.poster.ts       иллюстрация проблемы: FlowSpec с fixedStep
  components/FlowDiagram.tsx  React-остров со схемой
  code/registry.ts            единственное место, где резолвятся колоды и SVG
  components/DiagramDefs.astro общие defs схем: стрелки, тень
  content/lessons/<loc>/*.mdx нарратив + квиз, переводится
  content.config.ts           zod-схема урока
  components/StepPlayer.astro пошаговый плеер
  components/Quiz.astro       квиз, прогресс в localStorage
  i18n/ui.ts                  строки интерфейса, локали, localePath()
  pages/[lang]/               каталог и страница урока
scripts/check-steps.mjs       проверка консистентности локалей и колод
```

## UI

Сайт рассчитан на широкие экраны: схема и код стоят рядом, и на телефоне такой
разбор всё равно не читается. Узкие экраны не ломаются (схема уезжает над
нарративом, панель шагов не переносится), но целью не являются.

- **Тема** — кнопка в шапке переключает светлую и тёмную, выбор живёт в
  `localStorage`. Скрипт инлайновый и стоит в `<head>`: иначе при выбранной
  тёмной успевает мигнуть светлая. Без выбора идём за системной темой, поэтому
  тёмная палитра объявлена дважды — значения должны совпадать.
- **Фильтр по тегам** — несколько тегов складываются по ИЛИ: читатель ищет, а не
  сужает. Выбор пишется в адрес (`?tag=reliability`), так что подборку можно дать
  ссылкой. Без JS фильтр скрыт, все уроки видны.
- **Навигация между уроками** — соседи считаются в `getStaticPaths`, там же, где
  порядок каталога: два места, считающие порядок по-своему, рано или поздно
  разойдутся.
- **Шрифт пометок** — Caveat, SIL OFL 1.1, лежит в `public/fonts/` вместе с
  лицензией. Self-hosted: внешний запрос к CDN ради двух подписей не окупается.
  Подключены подмножества latin и cyrillic, предзагружается только то, которым
  написана текущая локаль. На русских страницах грузятся оба — кириллица под
  буквы, latin под точку и тире; это неизбежно и стоит 74 КБ сверху.
- **Клавиатура** — skip-link к содержимому, одинаковая рамка `:focus-visible` по
  всему сайту, шаги листаются стрелками.
